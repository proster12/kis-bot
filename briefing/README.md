# 미국주식 아침 브리핑 + 모의 운용 봇 (GitHub Actions)

매일 아침(화~토 오전 7시 17분, 한국시간) GitHub Actions가 자동으로 실행합니다.

1. 관심종목의 종가, RSI, 이동평균으로 **매수 후보 / 매도 후보 / 관망** 신호를 냅니다.
2. 종목별 **뉴스 헤드라인**을 모읍니다.
3. 미국 증권거래위원회(SEC) 공시에서 **내부자 장내 매수·매도**(Form 4)를 확인합니다.
4. 신호대로 **가상 계좌**에서 사고팔아 성적을 기록합니다. 손절·익절과 재매수 대기도 적용됩니다.
5. 카카오톡(또는 텔레그램)으로 요약을 보냅니다.

> **실제 주문은 내지 않습니다.** 한투 API는 2단계에서 붙입니다. 그 전에 이 가상 계좌로 몇 주간 규칙을 검증합니다.

## 폴더 구성
| 경로 | 내용 |
|---|---|
| `config/settings.yaml` | 신호 규칙, 가상 자금, 손절·익절 비율 (**여기만 고치면 됨**) |
| `main.py` | 실행 파일 |
| `bot/` | 시세, 신호, 뉴스, 내부자 거래, 가상 매매, 알림 |
| `data/` | 가상 계좌 상태(`paper_state.json`), 거래 내역(`trades.csv`) — 자동 생성 |
| `reports/` | 날짜별 전체 보고서 — 자동 생성 |
| `tests/` | 가짜 데이터로 하는 자체 테스트 (매 실행 전에 자동으로 돎) |

## 설치 순서

이 폴더는 `kis-bot` 저장소 안에 있고, 워크플로는 `.github/workflows/daily-briefing.yml`입니다.
한투 봇(`trader.py` 등)과는 따로 돌며, 관심종목은 최상위 `universe.txt`를 같이 씁니다.

### 1) 시크릿 등록
저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 필수 | 값 |
|---|---|---|
| `SEC_USER_AGENT` | **필수** | `이름 이메일` 형식 (예: `Cheolhee Kim myname@example.com`) — SEC가 요구 |
| `KAKAO_REST_API_KEY` | 카톡 받을 때 | airtable_alert에서 쓰는 카카오 앱의 REST API 키 그대로 사용 가능 |
| `KAKAO_REFRESH_TOKEN` | 카톡 받을 때 | 위와 같은 리프레시 토큰 |
| `KAKAO_CLIENT_SECRET` | 앱에 설정했을 때만 | 카카오 앱의 Client Secret |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | 선택 | 텔레그램으로 전체 보고서를 받고 싶을 때 |
| `FINNHUB_API_KEY` | 선택 | 넣으면 야후 대신 Finnhub 뉴스 사용 (무료 키) |

카카오 메시지의 **자세히 보기** 버튼이 열리려면 카카오 개발자 콘솔에 사이트 도메인을 등록해야 합니다.
위치: 내 애플리케이션 → 앱 설정 → 플랫폼 → Web → 사이트 도메인 → `https://github.com` 추가

### 2) 첫 실행
저장소 → **Actions** 탭 → (처음이면 활성화 버튼 클릭) → **미국주식 아침 브리핑** → **Run workflow**
→ 1~2분 뒤 실행 화면 아래쪽 **Summary**에서 전체 보고서를 확인합니다.

## 알아 둘 점
- 카카오 기본 메시지는 200자 제한이 있어 요약만 갑니다. 전체 보고서는 버튼 → Actions 요약 화면에서 봅니다.
- 카카오 리프레시 토큰은 약 2개월마다 갱신이 필요합니다. 실행 화면에 경고가 뜨면 시크릿을 새 값으로 바꾸세요.
- 시세는 야후 파이낸스(yfinance)에서 받습니다. 가끔 막히면 해당 종목이 "시세를 못 받은 종목"으로 표시됩니다.
- GitHub의 예약 실행은 수 분~수십 분 늦게 시작될 수 있습니다.
- 비공개 저장소의 무료 Actions 시간은 매월 2,000분입니다. 이 봇은 하루 2분 정도 씁니다.
- 이 저장소는 **공개(Public)** 저장소라 `briefing/reports`, `briefing/data`의 가상 매매 기록도 누구나 볼 수 있습니다. 시크릿(키·토큰)은 공개되지 않습니다.
